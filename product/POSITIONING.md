# 爪爪 · Paw Work — 产品定位（vNext）

> 用户语言。实现见 `docs/SESSION_WORKSPACE_RUNTIME.md` 与根 `AGENTS.md`。

---

## 一句话

**在真实网页上选出你要的东西，说清想要什么结果，把工作成果拿走。**

英文：

> **Select it. Describe the outcome. Get the deliverable.**

它不是「替你全自动漫游全网」的黑盒，也不是程序员终端 Agent。  
它是坐在**你已经打开、已经登录的浏览器世界**旁边的工作助手：你指范围，它交付可核对的结果。

---

## 气质

| 强调 | 避免 |
|------|------|
| 选中 → 说结果 → 交付 | 「浏览器 OS」「通用 RPA」口号先行 |
| 范围可预期、可停、可确认 | 静默扩大选区、假完成 |
| 零搬运：网页对象直接进任务 | 先下载再上传再解释上下文 |
| 高频整理 / 抽取 / 生成素材 | 承诺任意网站任意无人值守 |

---

## 给谁

- 在浏览器里做重复整理、对比、导出、素材处理的人  
- 已登录 SaaS / 店铺 / 文档页，不想再走 OAuth 拼装流水线  

## 不是谁的第一选择

- 需要 Docker / 本地 Shell / 百万文件仓库编程的开发者主战场（那是 Coding Agent）  
- 需要无人值守跨站支付 / 提交的全自动 RPA  

---

## 核心交互

1. **Paw 开** → 点选 / 多选（未来区域选）网页内容  
2. **说结果** → 自然语言描述 deliverable  
3. **核对与拿走** → 预览、文件、失败说清楚  

没有选中时，也可靠当前页 + 一句话开始；但**明确选择优先于猜测**。

---

## 结构优势（用户能感到的）

**Context Transfer Collapse：**  
不用「网页看见 → 复制下载 → 打开 AI → 上传 → 再说明」。  
变成「选中 → 说 → 拿到」。

更深能力（授权内读/写网页、批处理、可复用程序）是深度，不是第一句广告。

---

## 边界

- 默认不跑出你选出的范围；扩大范围要你说清楚或确认  
- 高风险动作（提交、付款、批量改写）需确认  
- 安装面 = Chrome 扩展；不要求本机装其它运行时
